# 카탄

주사위가 자원을 나눠주고, 자원으로 도로·마을·도시를 짓는 온라인 카탄입니다. 기본판과 「도시와 기사」 확장이 둘 다 있습니다.

![타이틀](assets/screenshots/title.png)

## 플레이

https://catan.41ways.workers.dev/

2~4인. 방 코드나 초대 링크로 붙고, 봇으로 채우면 혼자서도 연습할 수 있습니다. 계정은 없습니다.

## 규칙

기본판 그대로입니다. 땅 타일 19개(사막은 항상 한가운데), 항구 9개, 자원 5종을 주사위로 나눠 받아 도로·마을·도시를 짓습니다. 7이 나오면 카드 8장 이상인 사람은 절반을 버리고 도둑을 옮깁니다. 발전 카드로 기사·승점·독점 등을 쓸 수 있고, 최장 교역로와 최강 기사단은 각 2점입니다. 자기 차례에 10점을 넘기면 승리입니다.

혼자 연습(봇과)은 서버 없이 브라우저에서 돌아가고, 온라인 대전은 서버(Cloudflare Workers + Durable Object)가 판정을 맡습니다. 사람마다 자기가 볼 수 있는 정보만 전달되므로 남의 손패나 발전 카드 내용은 새 나가지 않습니다.

## 기술

정적 화면(`public/`)은 Cloudflare Workers 자산으로, 소켓과 상태 확인만 Durable Object 하나로 처리합니다. 로컬 개발은 Node(`server.js`)로 같은 `game.js`를 띄웁니다. 규칙 엔진(`rules.js`, `ck.js`)은 순수 함수라 서버와 화면이 같이 쓰고, 화면 쪽은 심볼릭 링크로 원본을 그대로 참조합니다.

```bash
npm install
npm start        # http://localhost:8878
npm test         # 규칙 · 봇 · 서버 시나리오 테스트
```

배포:

```bash
./bump.sh              # 자산 캐시 무효화
npx wrangler deploy
```

## 알려진 제약

관전 모드가 없고, 판에서 빠지면 다시 들어올 수 없습니다. 무를 수도 없습니다. 방은 서버 메모리에만 있어서 배포하면 열린 방이 사라집니다.
