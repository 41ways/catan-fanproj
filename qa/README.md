# 돌려 보고 확인하는 도구

눈으로 훑는 대신 **실제로 한 판을 끝까지 돌려서** 확인한다.
화면 쪽 조각(`scene.js`)은 `public/qa/` 에 있고 `?scene=` 으로 들어올 때만 불러온다. 혼자 하기만 쓰므로
판은 브라우저에서 돈다(서버는 화면 파일을 내주기만 한다).

```sh
PORT=8896 node server.js           # 프로젝트 폴더에서
sh qa/run.sh play base 3           # 기본판 3판을 끝까지 — JS 오류·미완주 확인
sh qa/run.sh pace ck               # 확장판 — 안내가 몇 초씩 떠 있었는지
```

## `scene.js` — 장면 만들기
`?scene=...` 로 특정 장면을 바로 띄운다. `qa`(한 판 자동 진행), `timing`(체류 시간 기록),
`card`·`ckcard`(카드 공개), `discard`, `order`, `over`, `hand`, `home` 등.

## `pace.py` — 너무 빨리 지나가는 안내 찾기
기준: 한글 안내는 **0.85초 + 글자당 0.075초**(초당 13자쯤) 이상 떠 있어야 하고,
전면 알림은 최소 1.5초, 중요한 문구(내 차례·도둑·버리기 등)는 1.6초 이상.
전면 알림이 **둘 이상 겹쳐 뜨면** 따로 잡아낸다.

숫자가 아니라 "빨라 보인다"로 판단하지 않기 위한 도구다. 연출을 건드리면 전/후를 비교한다.
